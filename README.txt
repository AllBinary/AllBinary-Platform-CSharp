                             AllBinary Platform C#

What is it?

This repository contains code generated by the AllBinary Platform in C#.  
This repo is used to allow developers to skip the C# code generation step.

What are some examples game with this C# code?

https://allbinary.itch.io (The downloads with "-cs" in the filename are C# only builds. Currently that only includes nothing. Also the C# builds are not available on Google Play or other stores.)
